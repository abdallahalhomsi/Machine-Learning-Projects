## How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/machine-learning-homeworks.git
cd machine-learning-homeworks
```

2. Install the required Python packages:

```bash
pip install -r requirements.txt
```

3. Open the notebooks:

```bash
jupyter notebook
```

or use JupyterLab:

```bash
jupyter lab
```
